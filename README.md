My entry for make.fun's "The Internet in One Word" bounty.

The internet in one word: **doomscroll** — endlessly scrolling through feeds, news and videos, long after you meant to stop.

## Run it

```sh
python3 main.py
```

`main.py` reads `entry.txt` in the repository root and writes its contents byte-for-byte to `/output/entry.txt`, creating `/output` if needed.
